# Урок наоборот 🚪

Интерактивный универсальный школьный лайфхак: три двери, голосование учеников, QR-код, результаты, рефлексия.

## Запуск
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Размещение
Создайте новый GitHub-репозиторий, загрузите `app.py` и `requirements.txt`, затем создайте приложение в Streamlit Community Cloud, указав `app.py`.

## Работа
1. Учитель создаёт комнату с темой и PIN.
2. Делится кодом/QR со школьниками.
3. Ученики выбирают одну из трёх дверей.
4. Учитель обновляет результаты, закрывает голосование, запускает соответствующий формат работы.
5. Ученики отмечают, насколько поняли тему.

## Важные ограничения
Это демонстрационная версия на локальной SQLite. В одном работающем экземпляре приложения голоса видны всем подключённым участникам; при перезапуске/пересоздании облачного сервера данные могут исчезнуть. Для постоянной эксплуатации в школе нужна внешняя база (например, Supabase/Postgres). Голосование ограничено идентификатором сессии браузера, а не личностью: повторное открытие страницы или другое устройство может дать дополнительный голос. Для официальных опросов это не подходит. Учителю нужно нажимать «Обновить результаты». PIN не защищает от перебора, поэтому не используйте личные пароли.
